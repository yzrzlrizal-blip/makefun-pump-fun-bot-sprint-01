Survivor Rider: a pump.fun replay paper bot that only buys coins that survived the rug window — at least 1500 slots old, 20+ trades printed, 2+ SOL of real reserves, price up 10% over its first print and over its own low — then rides them with a small 0.02 SOL stake and exits fast on a stop-loss, a give-back from the peak, or a max hold.

## Run it

```sh
node main.ts
```
